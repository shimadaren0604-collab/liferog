# ロブリック用プログラム

ロブリックの **JavaScript タブ** に貼って使います。

| ファイル | 内容 | 状態 |
|---|---|---|
| `いうこと聞くロボホン.js` | 「前」「後ろ」「右」「左」で歩いたり回ったりする。「おしまい」で終わる | ✅ 実機で動作確認済み |
| `いろいろテスト.js` | 動き・回る・速さ・英語・計算・歌・ダンスを順番に試す | ✅ 実機で動作確認済み（よろしくね の行を除く） |
| `if条件分岐テスト.js` | if / else if / && / \|\| / 入れ子 を試す | テスト中 |
| `かんたん英会話.js` | リストを使った3往復の英会話。通じないと "One more time" で聞き直す | テスト中 |
| `ボール蹴り.js` | ランダムな位置から声で案内してもらい、ボールを蹴る | テスト中 |

## 書くときの注意
- 古い JavaScript の書き方で書く（`var` を使う。`let` / `const` / `=>` は避ける）
- 1行目は必ず `Robohon.startBlocks();`
- 動き・速さ・言語などの名前は**変数で渡せない**（「引数が想定外の値」エラー）。`Robohon.move('右を向く')` のように必ず直接書く
- 聞いた言葉の判定は `Robohon.value('LastListenWord').indexOf('〜') >= 0`（「〜を含む」）
- 命令1つごとにロボホンとやりとりするので、命令（特に `changeTTS` の切り替え）が多いと反応が遅くなる。言語切り替えは最初と最後だけにする
- ブロックの XML ファイルを作って読み込む方法は、お使いのバージョンでは動かなかった

## JavaScript の命令（実機の画面から）
- しゃべる：`Robohon.speech('こんにちは');`
- しゃべりながら動く：`Robohon.speakmove('こんにちは', '右を向く');`
- 動く：`Robohon.move('右を向く');`
- 歩く・回る：`Robohon.stepMotion(3, '歩、前へ歩く');`
- 立つ・座る：`Robohon.standSit('立ち上がる');`
- 歌う・踊る：`Robohon.sing('ランダム');` / `Robohon.dance('ランダム');`
- 聞く：`Robohon.listenWaitAny();` → `Robohon.value('LastListenWord')`
- 写真：`Robohon.photo();`

## 実機で使えた名前
- `Robohon.move()`：`右を向く` / `下を向く` / `おやすみ` / `えへへ` / `満腹` / `小さく左手を上げる` / `左手を下げる` / `大きく右手を上げる` / `右手を下げる`
  - ❌ `よろしくね` は move では使えなかった（公式サンプルでは speakmove でのみ使われている）
- `Robohon.stepMotion()`：`歩、前へ歩く` / `歩、後ろへ歩く` / `回、右に回る` / `回、左に回る`
- `Robohon.changeSpeakSpeed()`：`とても遅く` / `ちょっと遅く` / `普通の速さに` / `ちょっと速く` / `とても速く`
- `Robohon.changeTTS()`：`英語` / `日本語`
- `Robohon.sing('ランダム')` / `Robohon.dance('ランダム')`
- `Math.random()` などふつうの計算も使える

## 公式サンプル（XML）から分かった選択肢（メモ）
※ JavaScript で使えるかは、まだ確認していない


### 歩く・回る（`robohon_step`）
- `歩、前へ歩く` / `歩、後ろへ歩く` / `回、右に回る` / `回、左に回る`

### 動き（`robohon_move` / しゃべりながら動く `robohon_speakmove`）
- `右を向く` / `下を向く` / `よろしくね` / `おやすみ` / `えへへ` / `満腹`
- `小さく左手を上げる` / `大きく右手を上げる` / `右手を下げる` / `左手を下げる`

### しゃべる速さ（`robohon_speakspeed`）
- `とても遅く` / `ちょっと遅く` / `普通の速さに` / `ちょっと速く` / `とても速く`

### 言語（`robohon_changetts` 話す言語 / `robohon_changeasr` 聞く言語）
- `日本語` / `英語` / `中国語`

### よく使う形
- 聞いて返事をする：`ずっと繰り返す` → `何か聞こえるまで待つ` → `もし（最後に聞こえた言葉）＝「〜」なら`
- 特定の言葉を待つ：`robohon_listenwait` に `終わり,終わって,消す` のようにカンマ区切りで並べる
- 合言葉で起動する：`robohon_listenStart` に `キョウノランチ` のようにカタカナで書く
- 写真：`写真をとる` → `写真を表示（最新の写真）` → `写真の表示をやめる`
- 顔を見つける：`顔検出（短め）` → `もし 顔が見つかったら`
